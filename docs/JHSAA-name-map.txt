WHAT THIS IS. The tennis association (the JHSAA) is built from THIS repo's
institution records, and it renames a lot of them at emit. This repo keeps the
published record under the ORIGINAL names, so the two disagree ON PURPOSE. This
file is the mapping, written down so that anybody reading a record here and
finding a different name in the tennis coverage knows why, and so the eventual
sync has a plain-text reference that does not require reading Python.

IT IS NOT AN INSTRUCTION TO RENAME ANYTHING HERE. The sync is approved but
deferred — see docs/NOTE-tennis-association-name-changes.md. When it is run it
is run by scripts/rename_prep_network.py off the authoritative tables in the
tennis repo, never by hand off this file.

  * SOURCE  — the name in records/orgs/schools.json
  * BECOMES — the name the tennis association uses
